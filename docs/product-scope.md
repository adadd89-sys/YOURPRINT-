# YOURPRINT — initial product scope

## Customer flow
1. Open the Mini App from the Telegram channel/bot.
2. Choose DTF printing.
3. Select ready artwork or request a new design.
4. Provide order details and clothing sizes where relevant.
5. Submit the order and communicate with the administrator in Telegram.
6. Receive status updates and a photo when the order is complete.

## Sizes
XS, S, M, L, XL, XXL, XXXL, Universal.

## Order and admin capabilities
- Shared customer and order database.
- Repeat orders.
- Promo codes and discounts.
- Notifications on every order status change.
- Administrators can create orders manually and track deadlines.
- One initial administrator; ability to add more administrators.
- Payment arrangements are handled directly in Telegram, outside the Mini App.

## Out of scope for first release
- Printing methods other than DTF.
- Mass messaging.
- Analytics dashboard.
